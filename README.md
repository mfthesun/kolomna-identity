# Коломна: исследование локальной идентичности

Данные, код и отчёт учебного группового проекта по дисциплине «Городская идентичность в управлении градостроительным развитием» (ИТМО): локальная идентичность исторического района Коломна в Петербурге — четыре компонента идентичности (когнитивный, аффективный, ценностно-смысловой, практический), четыре версии границ, наследие, демография и карты.

**Итоговый отчёт: [Коломна_исследование.pdf](Коломна_исследование.pdf)** — 19 страниц, разделы I–IV ТЗ, все цифры воспроизводимы ноутбуками из этого репозитория.

## Ключевые выводы

1. **Границы расходятся в 2,8 раза по площади.** МО Коломна (2,49 км²) почти совпадает с краеведческой «Коломной трёх островов» (1,81 км²); туристическая и литературная Коломна «расползаются» на восток через Крюков канал — к Мариинке, Театральной и Сенной площадям (5,08 км²).
2. **Чем дальше от Крюкова канала, тем тише.** Кафе и ресторанов по OSM — 55 на км² в ядре, 171 в «литературном» кольце; вся торговля и услуги — 205 против 582. Тишина — главный аффективный ресурс района.
3. **Ценность Коломны — среда, а не отдельные памятники.** В ЕГРОКН внутри МО 93 объекта (в максимальной Коломне — 311), ИСС КГИОП добавляет 66 и 198 выявленных ОКН — в основном рядовые доходные дома XIX века. Рядовая застройка держится на зонах охраны, а не на реестре.
4. **Идентичность держится на литературном мифе:** Гоголь («тут не столица и не провинция»), «Домик в Коломне» Пушкина, Блок у Пряжки — и «Пряжка» как городское имя психиатрической больницы.
5. **Главный фактор перемен — метро «Театральная»** (вестибюль на площади Темирканова, открытие 2029–2030) и девелопмент западного края (ЖК на Матисовом острове, концертный комплекс и мост на Ново-Адмиралтейском): они снимут труднодоступность, на которой держится тишина.

## Как воспроизвести

Полностью — в Google Colab (для `geopandas`/`osmnx` проще всего), частично — локально.

**1. Клонируйте репозиторий.** В Colab положите клон в корень Google Drive как `kolomna-identity` (или поправьте `PROJECT_DIR` в первой ячейке каждого ноутбука). Локально ноутбуки сами используют текущую папку.

**2. (по желанию) Полные исходники.** Репозиторий работает без них: при отсутствии файлов ноутбуки берут готовые выборки из `kolomna_data/`. Чтобы пересобрать всё с нуля, положите в корень:
- `data-69-structure-16.json/` — выгрузка ЕГРОКН (Минкультуры, 17 файлов, 163 240 записей);
- `HOITH_database_231118.gpkg` — «Карта возраста домов» (1,8 ГБ), вырезается командой:

  ```bash
  ogr2ogr -f GPKG hoith_kolomna.gpkg HOITH_database_231118.gpkg \
          -spat 30.255 59.910 30.335 59.942 -spat_srs EPSG:4326
  ```
  (в репозитории вырезка уже есть — `hoith_kolomna.gpkg`, слой `all_cities_181123`, год в `r_year_int`).

**3. Запустите** `01_kolomna_data.ipynb` → дополнит `kolomna_data/`, напечатает все таблицы отчёта. Затем `02_kolomna_maps.ipynb` → PNG в `kolomna_maps/`.

**4. Скрипты отдельно (локально, нужен poppler-utils):**

```bash
# таблица населения МО из PDF Петростата
python3 scripts/population_from_pdfs.py sources_petrostat out.csv

# возрастно-половой состав по районам
python3 scripts/age_sex_from_pdf.py "sources_petrostat/14001024_Возраст-пол нас СПб 2024.pdf" out.csv

# фильтр выгрузки ИСС КГИОП по Коломне и сверка с ЕГРОКН
# (нужен исходный CSV ИСС от 09.10.2026 — файл 2026-10-09_14-35-23.csv)
python3 scripts/kgiop_filter.py 2026-10-09_14-35-23.csv kolomna_data/egrokn_spb_all.csv \
        hoith_kolomna.gpkg kolomna_data/kolomna_boundary_variants.geojson kolomna_data
```

## Источники данных

- **ЕГРОКН** (Минкультуры России), выгрузка `data-69-structure-16`;
- **ИСС КГИОП**, выгрузка сведений об ОКН по Петербургу от 09.10.2026;
- **«Карта возраста домов»** (HOITH), выгрузка 18.11.2023;
- **OpenStreetMap**: отношения МО 1121517 и островов, точки shop/amenity/tourism (Overpass API, с кэшем и датой выгрузки);
- **Петростат**: численность населения по МО на 01.01.2018–2025, ВПН-2010/2020, бюллетень 14001024 «Возрастно-половой состав» (PDF в `sources_petrostat/`);
- **Яндекс Карты**: полигон исторического района, панорамы (наблюдения October 2026);
- тексты: Википедия, Горбачевич и Хабло «Почему так названы?», Зуев «Петербургская Коломна», In Your Pocket, Т—Ж, KudaGo, ДП/Фонтанка (новости проектов), Гоголь «Портрет», Пушкин «Домик в Коломне» — полный список в конце отчёта.

## Оговорки по точности

Цифры по OSM посчитаны 8 октября 2026 года по центрам объектов и при перезапуске могут отличаться на единицы (OSM меняется ежедневно; дата выгрузки сохраняется в кэше `_fetched`). У 586 записей ЕГРОКН по СПб нет координат — три привязаны по адресу явным списком. Координаты ИСС КГИОП в выгрузке отсутствуют — привязка по адресам «Карты возраста домов» и ЕГРОКН (91 %), по наименованию, комплексу и вручную. Демография по МО — оценки; возрастно-половой состав публикуется только по районам.

## Статус проекта

Готов кабинетный этап (разделы I–II ТЗ). Впереди — полевой этап (ментальные карты 15–20 респондентов, экспресс-интервью, go-along, подсчёт пешеходов в трёх точках, фотофиксация), разделы III–IV (взгляд профессионала и предложения по развитию) и презентация. В ноутбуке 02 для них уже есть заготовки: карта 6 (ментальные карты, ждёт `mental_maps.geojson`) и карта 7 (маршрут go-along, ждёт `route.geojson`).
