# Как править презентацию Коломны

Презентация собирается как PDF из заранее отрисованных PNG-слайдов. PPTX в текущем пайплайне не используется, потому что при ручной сборке PowerPoint разъезжались текст и изображения.

## Главный файл

Скрипт сборки:

```text
scripts/create_kolomna_pdf.py
```

Финальные файлы:

```text
output/Коломна_презентация_финальная.pdf
output/kolomna_pdf_slides/slide_01.png … slide_12.png
```

После любой правки нужно запускать:

```bash
python scripts/create_kolomna_pdf.py
```

Скрипт заново создаёт все PNG и объединяет их в один PDF.

## Как устроен скрипт

В начале файла находятся:

- размеры страницы: `W = 1920`, `H = 1080`;
- цвета презентации: `PAPER`, `NAVY`, `CORAL`, `BLUE`, `OCHRE`;
- пути к картам и фотографиям в словаре `AS`;
- функции `fit`, `contain` и `put` для размещения изображений;
- функции `heading`, `txt` и `footer` для текста.

Каждый слайд описан отдельным блоком ниже списка `slides = []`. Блок создаёт изображение `im`, рисует на нём текст и вставляет фотографии или карты, затем добавляет его через `slides.append(im)`.

## Как менять текст

Текст находится прямо в блоках слайдов. Например:

```python
im=page()
d=heading(
    im,
    '01 / ТЕРРИТОРИЯ',
    'Четыре Коломны',
    'Официальная граница почти совпадает с ядром'
)
```

Для крупного текста используется:

```python
txt(d, (72, 105), 'Заголовок', 58, INK, True, True, maxw=1660)
```

Параметры:

- `(x, y)` — координаты верхнего левого угла;
- число после текста — размер шрифта;
- `True` после цвета — жирный шрифт;
- следующий `True` — Georgia вместо Arial;
- `maxw` — максимальная ширина блока с автоматическим переносом.

Всегда задавайте `maxw` для длинных заголовков и подписей. Не размещайте длинный текст поверх карты или фотографии.

## Как менять карты

Актуальные карты лежат здесь:

```text
kolomna_maps/carto_positron_wide/
```

Сейчас используются:

```text
01_kolomna_boundaries_carto_positron.png
02_kolomna_okn_carto_positron.png
04_kolomna_building_age_carto_positron.png
05_kolomna_dominants_projects_carto_positron.png
```

Путь к карте меняется в словаре `AS`. Для карт используется `contain`, а не `fit`: карта сохраняет пропорции и не обрезается.

Пример:

```python
put(im, 'age', (110, 330, 1810, 990), 'contain')
```

Если нужно заменить карту, лучше сохранить тот же размер и имя файла. Если меняется имя, нужно также изменить путь в `AS`.

## Как менять фотографии

Фотографии для презентации находятся в:

```text
kolomna_photos/
```

Для презентации отобраны файлы с префиксом `PRES_`. Их тематическая группировка описана в `kolomna_photos/README.md`.

Фотография с заполнением блока:

```python
put(im, 'bridge', (0, 0, 1920, 1080), 'fit')
```

Режим `fit` заполняет весь блок и может обрезать края. Для важных деталей используйте подходящий формат блока или `contain`.

HEIC-файлы старого набора в текущем окружении обычно читаются через Pillow. Если новый HEIC не открывается, замените его на JPG/PNG с тем же содержанием и обновите путь в `AS`.

## Логика текущих 12 страниц

1. Титульный слайд.
2. Четыре версии границ Коломны.
3. Вода, застройка, адреса и дворы как визуальные признаки района.
4. Четыре компонента идентичности.
5. Тишина и плотность сервиса.
6. ОКН и пространственная концентрация наследия.
7. Возраст рядовой застройки.
8. Литературные и городские мифы.
9. Группы пользователей района.
10. Метро, проекты и возможная потеря приватности.
11. Один отдельный кейс: Дом Иофа / «Рекорд».
12. Общий вывод по Коломне.

«Рекорд» специально оставлен одним кейсом. Он не должен заменять основную логику исследования про территорию, среду, наследие и будущее района.

## Что проверить после правок

1. Запустить `python scripts/create_kolomna_pdf.py`.
2. Открыть PNG из `output/kolomna_pdf_slides/` и проверить каждый слайд.
3. Проверить, что текст не выходит за границы своей колонки.
4. Проверить, что фото не перекрывают заголовки и подписи.
5. Проверить карты на отсутствие обрезки и читаемость легенды.
6. Открыть итоговый PDF и проверить порядок страниц.

Не правьте готовый PDF вручную: при следующем запуске он будет создан заново из скрипта.
