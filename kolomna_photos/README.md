## Личные фотографии для презентации

Файлы с префиксом `PRES_` отобраны по темам исследования:

- `PRES_01`–`PRES_02`, `PRES_06`, `PRES_11`, `PRES_14` — вода, мосты, порт и пространственная рамка Коломны;
- `PRES_03`–`PRES_04`, `PRES_07`, `PRES_12`, `PRES_15`, `PRES_18`, `PRES_21` — локальные знаки, детали и самоидентификация района;
- `PRES_05`, `PRES_10`, `PRES_16`, `PRES_19`–`PRES_20` — религиозное и историческое наследие;
- `PRES_08`–`PRES_09`, `PRES_17` — состояние рядовой застройки, память и конфликт развития;
- `PRES_13` — группа в публичном пространстве, подходит для финального слайда о восприятии района.

Это личные фотографии группы; отдельная лицензия Wikimedia для них не применяется.
